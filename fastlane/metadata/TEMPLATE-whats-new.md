# Шаблон release notes

Контракт:
- Готовый файл сохранить как `fastlane/metadata/android/<locale>/whats_new/<VERSION_NAME>.txt`,
  где `<locale>` — `ru-RU` (обязательно) или `en-US` (опционально), `<VERSION_NAME>` —
  точное значение из `gradle.properties` (например, `1.13.2`).
- Один файл на одну версию, перезаписывается при повторном релизе той же версии.
- `whats_new/<VERSION_NAME>.txt` коммитится в репозиторий.
