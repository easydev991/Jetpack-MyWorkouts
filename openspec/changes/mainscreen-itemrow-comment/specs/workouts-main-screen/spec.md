# Spec Delta

## ADDED Requirements

### Requirement: Комментарий в строке записи

Строка записи на главном экране SHALL отображать комментарий к записи о
выполнении отдельной строкой после блока дополнительного веса, а при
отсутствии веса — сразу под строкой «название — значение». Комментарий
SHALL выводиться как есть, без ведущей метки слева (в отличие от строки
веса). Стиль комментария SHALL соответствовать `bodyMedium` с цветом
`onSurfaceVariant`. Комментарий SHALL занимать максимум 2 строки: при
переполнении — обрезаться с многоточием.

Когда комментарий записи отсутствует (`null`) или состоит только из
пробельных символов (blank), блок комментария SHALL NOT отображаться —
вид строки записи идентичен текущему.

#### Scenario: Короткий комментарий отображается целиком

- **WHEN** список отображает запись с непустым комментарием «сразу после
  сна», умещающимся в две строки
- **THEN** комментарий отображается под строкой «название — значение»
  (или под строкой веса, если вес есть) без ведущей метки
- **AND** стиль отличается от основной строки (менее акцентный)

#### Scenario: Длинный комментарий обрезается в две строки с многоточием

- **WHEN** список отображает запись с комментарием длиннее двух строк
- **THEN** комментарий занимает не более двух строк
- **AND** конец текста заменён многоточием (переполнение `Ellipsis`)

#### Scenario: Пустой комментарий не отображается

- **WHEN** список отображает запись, у которой комментарий `null` или
  состоит только из пробельных символов (blank)
- **THEN** блок комментария не отображается
- **AND** строка записи выглядит так же, как до этого изменения

#### Scenario: Комментарий у записи без веса

- **WHEN** список отображает запись без дополнительного веса
  (`weight_kg` — `null` или 0), но с непустым комментарием
- **THEN** комментарий отображается сразу под строкой «название —
  значение»
- **AND** строка веса не отображается
