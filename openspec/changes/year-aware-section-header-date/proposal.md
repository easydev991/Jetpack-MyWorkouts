# Proposal

## Why

В `EntryListItems` главного экрана (MainScreen.kt:329) дата секции
форматируется одним шаблоном `dd.MM.yyyy` и затем передаётся готовой
строкой в `SectionHeader` — одинаково и для текущего
года, и для архивных дат. Для тренировок этого года год избыточен
(«19.09.2026» съедает место, которое лучше отдать под день недели
и месяц). Архивные даты (прошлые годы) должны остаться однозначно
идентифицируемыми — там год нужен.

## What Changes

- `MainScreen.kt`: вместо единственного `DateTimeFormatter.ofPattern(
  "dd.MM.yyyy")` для датированных секций (не «Сегодня», не «Вчера») —
  выбор форматтера по году:
  - `LocalDate.now().year == sectionDate.year` → `"EEE, d MMM"`
    (ru: `Сб, 19 сент.`, en: `Sat, 19 Sep`).
  - иначе → `"EEE, dd.MM.yyyy"` (ru: `Пт, 19.09.2025`, en:
    `Fri, 19.09.2025`).
- Локализация — `DateTimeFormatter.ofPattern(..., Locale.getDefault())`:
  сокращения `EEE` и `MMM` подставляются локально, ручного форматирования
  нет. ru/en идут одним шаблоном, без ветвления по локали. Точка после
  сокращённого месяца в ru (`сент.`, `янв.`) — стандартный вывод JDK,
  кастом не нужен.
- `DateSection` / `groupEntriesByDate` не меняются: `LocalDate` уже
  доступен в `section.date`, ветка выбора — только в `EntryListItems`.
- `MainScreenSectionsTest`: копия форматтера в тесте (`val
  dateFormatter` на строке 67, вызовы на строках 164 и 183)
  обновляется под новый контракт. Добавляются четыре
  androidTest-кейса: по одному на оба варианта (этот год / прошлый
  год) с фиксированными датами — граница «этот год» через текущий год
  на момент запуска нестабильна — и их ru/en-дубли с явной установкой
  JVM-локали (tasks §1.3). Существующие тесты на `today.minusDays(5)`
  остаются зелёными при любом годе запуска: в 2027 их ожидаемая
  строка через ту же функцию выбора переключится на формат с годом.

### New Capabilities

### Modified Capabilities

- `workouts-main-screen`: требование «Список записей разделён на секции
  по дате» — заголовок датированной секции (не «Сегодня», не «Вчера»)
  зависит от года секции: для текущего года — день недели + день и
  месяц без года, для прошлых годов — день недели + `dd.MM.yyyy`.

## Impact

- `app/src/main/java/com/myworkouts/ui/screens/main/MainScreen.kt:329`
  — заменить одиночный `DateTimeFormatter.ofPattern("dd.MM.yyyy")` на
  выбор из двух по году.
- `app/src/androidTest/java/com/myworkouts/ui/screens/main/MainScreenSectionsTest.kt`

  вызовы на строках 164 и 183) и существующие
  ожидаемые строки под новый контракт; добавить отдельные тесты на
  формат «этот год» и «прошлый год» с фиксированными датами;
  локализованные тесты — `Locale.setDefault` + `@After`
  восстановление (tasks §1.3).
- `app/src/main/java/com/myworkouts/ui/screens/main/MainScreenPreview.kt`

- `DateSection`, `groupEntriesByDate`, `EntryListItemRow`, ресурсы,
  локализация — не затрагиваются.
- Схема БД, миграции — не затрагиваются.
