## ADDED Requirements

### Requirement: Удаление записи о выполнении

Существующая запись о выполнении SHALL быть удаляемой. Удаление SHALL быть
безусловным: на запись нет внешних ссылок, она — лист дерева зависимостей.
Удаление SHALL возвращать `Result` с информацией об успехе или ошибке;
запись SHALL быть удалена из базы только при успешном результате.

#### Scenario: Удаление существующей записи

- **WHEN** вызывается удаление записи с идентификатором, существующим
  в таблице
- **THEN** операция завершается успехом
- **AND** запись отсутствует в базе при последующем чтении

#### Scenario: Удаление несуществующей записи

- **WHEN** вызывается удаление записи с идентификатором, отсутствующим
  в таблице
- **THEN** операция завершается успехом (отсутствие строки не является
  ошибкой — идемпотентность)

### Requirement: Удаление упражнения из каталога

Существующее упражнение каталога SHALL быть удаляемым при выполнении обоих
условий: упражнение создано пользователем (`isCustom = true`) и на него
не ссылается ни одна запись о выполнении. Удаление SHALL возвращать
`Result` с информацией об успехе или ошибке. Стандартное упражнение
(`isCustom = false`) SHALL быть неудаляемым: репозиторий отклоняет запрос.
Пользовательское упражнение, на которое ссылается хотя бы одна запись,
SHALL быть неудаляемым: SQL-ограничение `NO ACTION` отклоняет удаление,
репозиторий переводит ошибку в `Result.failure` с осмысленным сообщением
о необходимости сначала удалить записи. Запрос удаления упражнения с
идентификатором, отсутствующим в каталоге, SHALL завершаться ошибкой:
запрашиваемой цели удаления не существует (в отличие от записи, где
отсутствие строки идемпотентно).

#### Scenario: Удаление несуществующего упражнения отклоняется

- **WHEN** вызывается удаление упражнения с идентификатором, отсутствующим
  в таблице `exercises`
- **THEN** операция завершается ошибкой
- **AND** каталог остаётся без изменений

#### Scenario: Удаление пользовательского упражнения без записей

- **WHEN** вызывается удаление пользовательского упражнения,
  на которое не ссылается ни одна запись
- **THEN** операция завершается успехом
- **AND** упражнение отсутствует в каталоге при последующем чтении

#### Scenario: Удаление стандартного упражнения отклоняется

- **WHEN** вызывается удаление стандартного упражнения
  (`isCustom = false`)
- **THEN** операция завершается ошибкой
- **AND** упражнение остаётся в каталоге

#### Scenario: Удаление пользовательского упражнения с записями отклоняется

- **WHEN** вызывается удаление пользовательского упражнения,
  на которое ссылается хотя бы одна запись
- **THEN** операция завершается ошибкой
- **AND** упражнение остаётся в каталоге
- **AND** все связанные записи остаются без изменений
