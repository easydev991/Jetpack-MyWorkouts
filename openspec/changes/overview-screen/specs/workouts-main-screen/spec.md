# Spec Delta

## ADDED Requirements

### Requirement: Кнопка обзора в TopAppBar

`TopAppBar` главного экрана SHALL отображать справа кнопку со стандартной
иконкой `donut_large`, открывающую экран обзора (маршрут `overview`,
спека `overview-screen`). Кнопка SHALL отображаться только когда в списке
записей есть хотя бы одна запись; при пустом списке кнопка SHALL NOT
отображаться, а `TopAppBar` — оставаться в текущем виде (только заголовок).
Кнопка SHALL иметь локализованное описание доступности (ru/en). Остальное
поведение главного экрана (FAB, список, контекстное меню, карточка
деталей) SHALL NOT изменяться.

#### Scenario: Непустой список — кнопка видна

- **WHEN** на главном экране есть хотя бы одна запись
- **THEN** в `TopAppBar` справа отображается кнопка с иконкой `donut_large`

#### Scenario: Пустой список — кнопка скрыта

- **WHEN** все записи удалены и список пуст
- **THEN** кнопка обзора не отображается, `TopAppBar` содержит только заголовок

#### Scenario: Открытие обзора

- **WHEN** пользователь нажимает кнопку обзора
- **THEN** открывается экран обзора
- **AND** системная кнопка Back возвращает на главный экран
