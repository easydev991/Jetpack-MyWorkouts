## Why

Поле «Подходы» на экране создания записи показывается до выбора упражнения,
хотя типозависимое поле (повторы/длительность) уже прячется — поведение
полей формы несогласованно. Доп. вес поддержан слоем данных (`weight_kg`
в `ExerciseEntryEntity` и доменной модели, различие `null`/`0` покрыто
тестами), но UI не даёт его ввести.

## What Changes

- Поле «Подходы» прячется до выбора упражнения — вместе с полем
  повторы/длительность; после выбора оба появляются.
- После выбора упражнения под полем повторов/длительности появляется
  опциональное поле «Доп. вес»:
  - десятичный ввод в килограммах (дробные значения допускаются);
  - по умолчанию подставлен 0 — «без доп. веса», менять не обязательно;
  - на доступность сохранения не влияет (`canSave` без изменений).
- Введённое значение сохраняется в существующую колонку `weight_kg`;
  слой данных не меняется.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `workout-entry-screen`: правило видимости поля «Подходы» (после выбора
  упражнения, как и типозависимое поле); состав полей дополняется
  опциональным «Доп. вес» — правила ввода (десятичные, кг), дефолт 0,
  сохранение в `weightKg`.

## Non-Goals

- Отображение веса в списке записей (`EntryListItemRow`) — отдельное
  изменение (`entry-list-weight-display`: `weight_kg` в `observeEntries`,
  доменная модель, форматирование). При нём целые веса отображаются без
  дробной части («5 кг», не «5.0 кг»).

## Impact

- `ui/screens/entry/EntryCreateScreen.kt` — условный рендер поля подходов;
  новое поле веса в форме.
- `ui/screens/entry/EntryCreateFields.kt` — ввод десятичных чисел
  (расширение `NumberEntryField` параметром клавиатуры Decimal).
- `ui/state/EntryCreateUiState.kt` — текст поля веса (парсинг в `Double` —
  в `EntryCreateViewModel.save()`).
- `ui/viewmodel/EntryCreateViewModel.kt` — `onWeightChange` с санитайзингом
  десятичного ввода; прокидывание веса в `save()`.
- Строковые ресурсы ru/en — «Доп. вес (кг)».
- Тесты: юнит `EntryCreateViewModelTest` (ввод/санитайзинг/сохранение веса),
  Compose `EntryCreateScreenTest` (видимость полей, поле веса); превью.
