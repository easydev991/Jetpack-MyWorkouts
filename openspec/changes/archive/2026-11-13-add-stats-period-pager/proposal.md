# Proposal

## Why

Вкладка «Статистика» показывает данные только за одно окно — скользящее
окно, заканчивающееся сегодня. Пользователь, который хочет сравнить
сегодняшние результаты с прошлой неделей или прошлым месяцем, обязан
переключать тип периода и терять текущий контекст; при этом не видно, за
какие именно даты построены данные. Свайп по окнам периода закрывает обе
проблемы: листание истории без смены типа периода и постоянно видимый
диапазон дат под пикером.

## What Changes

- Вкладка «Статистика» получает навигацию по окнам выбранного периода:
  свайп вправо (содержимое уходит вправо) открывает более раннее окно, свайп
  влево — более позднее. Свайп за границу недоступен: вперёд листать некуда
  (окна всегда заканчиваются сегодня), назад — только до окна, пересекающегося
  с самой ранней тренировкой.
- Под пикером периода появляется подпись дат выбранного окна: для
  «Дня» — дата дня, для остальных — диапазон дат окна. Подпись обновляется
  при свайпе и показывает, за какие даты построены данные.
- Состояние экрана становится двумерным: тип периода × смещение окна.
  Смена типа периода возвращает актуальное окно; drill-down при свайпе
  сбрасывается к обзору категорий (как при смене периода).
- Расчёт статистики в домене учитывает смещение окна; окно периода и его
  границы становятся явной доменной величиной.
- Форматирование подписи дат выносится в общий модуль UI-утилит и
  локализуется по локали устройства (ru/en): названия месяцев — форматная
  форма ICU (ru — «ноября», en — «November»), разделитель диапазона —
  существующий строковый ресурс.
- Пикер периода остаётся сегментированным на всю ширину (визуально
  согласованный вариант выбран владельцем 12.11): меняется только появление
  подписи под ним; в портретной раскладке пикер с подписью
  дополнительно выносится из ленивого скролла в фиксированный блок над
  пагером (Impact, D7).
- Свайп фиксируется в аналитике как отдельное пользовательское действие.

## Capabilities

### New Capabilities

- Нет.

### Modified Capabilities

- `overview-screen`: требования «Статистика — период и донат долей категорий»
  и «Ландшафтная раскладка статистики» дополняются навигацией по окнам и
  подписью дат; «Drill-down категории в статистике» — сбросом drill-down при
  свайпе; «Актуальность данных обзора» — правилами переживания и
  неперсистентности смещения окна; ADDED — требования «Навигация по окнам
  периода свайпом» и «Подпись дат выбранного окна периода».

## Impact

- **Домен**: `domain/usecase/StatsWindow.kt` (новый) — доменное окно периода
  `StatsWindow` и `StatsPeriod.window(today, offset)`;
  `domain/usecase/ComputeCategoryStats.kt` — расчёт агрегатов по всем окнам
  за один проход (`computeCategoryStatsWindows`) и делегирование прежней
  функции смещению 0; `domain/usecase/StatsPeriod.kt` — длина окна без
  изменений.
- **Состояние**: `ui/state/OverviewUiState.kt` — в `StatsUiState` добавляются
  смещение окна, границы окна и карта агрегатов по смещениям; плоские поля
  `categoryTotals` / `exerciseTotals` / `drillGroups` и поле `isEmpty`
  заменяются картой (D5); `ui/viewmodel/OverviewViewModel.kt` — новое
  пользовательское состояние и действие смены окна, сброс смещения при смене
  типа периода.
- **UI**: `ui/screens/overview/StatsScreen.kt` — `HorizontalPager` с контентом
  статистики, подпись дат под пикером, портретная и ландшафтная
  раскладки; в портрете пикер с подписью выносится из ленивого
  скролла в фиксированный блок над пагером; `ui/util/` — форматтер подписи
  окна (чистые функции + обёртка).
- **Ресурсы**: строки `overview_*` в `values/strings.xml` и `values-en/strings.xml`
  (разделитель диапазона переиспользуется; новых строк не требуется —
  названия месяцев берутся из ICU).
- **Аналитика**: `analytics/AnalyticsEvent.kt` — новое действие пользователя
  для свайпа окна.
- **Тесты**: JVM-тесты доменного окна, форматтера подписи и ViewModel;
  androidTest на свайп, границы и подпись.
- **Скриншоты маркетплейса**: кадр вкладки «Статистика» меняется (пикер с
  подписью дат вынесен в фиксированный блок, D7) — перегенерируются
  `fastlane/metadata/android/ru-RU/images/phoneScreenshots/4-week-stats.png` и
  `fastlane/metadata/android/en-US/images/phoneScreenshots/4-week-stats.png`
  (`make screenshots{,-ru,-en}`, задача 5.4); прогон перегенерирует все кадры
  (демо-даты якорятся к `LocalDate.now()`), кадры без изменений фичи
  восстанавливаются из HEAD в задаче 5.4.
- **Зависимости**: `androidx.compose.foundation` (`HorizontalPager`) —
  объявляется явно: алиас `androidx-compose-foundation` в
  `gradle/libs.versions.toml` (без версии — версию задаёт BOM) и строка
  `implementation(libs.androidx.compose.foundation)` в
  `app/build.gradle.kts` (сейчас подтягивается транзитивно через
  material3; транзитивная зависимость не должна быть частью контракта
  кода — D9).
- **Черновики**: временный файл `StatsPeriodPickerDrafts.kt` удаляется после
  реализации.
