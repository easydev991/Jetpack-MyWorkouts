## MODIFIED Requirements

### Requirement: Формат значения записи

Значение в строке записи SHALL формироваться по количеству подходов:
при нескольких подходах — «подходы × значение» (например «4 х 10»), при
одном подходе — только значение (например «10»).

Для упражнений на время схема та же, но значение SHALL быть
человекочитаемой длительностью — в формате экрана создания записи:

- менее 60 секунд — «N сек»;
- 60 секунд и более — «M мин S сек», нулевые части опускаются;
- 1 час и более — часы через plurals «час/часа/часов»
  (максимум пикера — 3600 секунд = «1 час»).

Формат повторов не меняется. Тип значения (повторы или длительность)
определяется записью: длительность форматируется, только когда у записи
нет повторов.

#### Scenario: Несколько подходов с повторами

- **WHEN** запись содержит 4 подхода по 10 повторов
- **THEN** значение отображается как «4 х 10»

#### Scenario: Один подход с повторами

- **WHEN** запись содержит 1 подход по 10 повторов
- **THEN** значение отображается как «10»

#### Scenario: Несколько подходов с длительностью

- **WHEN** запись содержит 3 подхода по 20 секунд
- **THEN** значение отображается как «3 х 20 сек»

#### Scenario: Один подход с длительностью

- **WHEN** запись содержит 1 подход длительностью 20 секунд
- **THEN** значение отображается как «20 сек»

#### Scenario: Ровно минуты без секунд

- **WHEN** запись содержит 1 подход длительностью 120 секунд
- **THEN** значение отображается как «2 мин» (нулевая часть секунд
  опускается)

#### Scenario: Минуты и секунды при нескольких подходах

- **WHEN** запись содержит 4 подхода по 150 секунд
- **THEN** значение отображается как «4 х 2 мин 30 сек»

#### Scenario: Час через plurals

- **WHEN** запись содержит 1 подход длительностью 3600 секунд
- **THEN** значение отображается как «1 час» (слово «час» — из
  plurals-ресурса `entry_duration_hours`, склоняется: «2 часа»,
  «5 часов»)
