# Proposal

## Why

Восстановление после «Удалить все данные» (или чистой установки) теряет архивацию
стандартных упражнений: merge дедуплицирует по имени и пропускает существующие
записи целиком, а свежепересеянный каталог — весь активный. Признак `isArchived`
в файле есть и парсится, но для дедуплицируемых имён игнорируется (спека
«Признак архивации существующего упражнения при дедупликации не меняется»,
после задачи 4.1 — «Разархивация существующего упражнения из файла
не выполняется»).
Пользователь восстанавливает копию и получает все упражнения активными.

## What Changes

- Дедупликация по имени получает одностороннее правило для архивации: если
  в файле `isArchived = true`, а существующее упражнение активно, оно
  перемещается в архив.
- Обратная разархивация по-прежнему не выполняется: файл с `isArchived = false`
  не вынимает существующее упражнение из архива — путь молчаливой потери
  решений пользователя не создаётся.
- `iconNumber` существующего упражнения при дедупликации по-прежнему не
  меняется (иконки чистой установки не затираются `null` из старых бэкапов).

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `app-data-management`:
  - **MODIFIED** требование «Восстановление из резервной копии слиянием» —
    к правилу «существующее не изменяется» добавлено единственное исключение:
    односторонняя архивация по признаку из файла; добавлен сценарий
    «Архивация существующего упражнения из файла применяется», а сценарий
    «Признак архивации существующего упражнения при дедупликации не
    меняется» переработан под обратное направление (файл `false` при
    архивном существующем — разархивации нет; имя сохранено, финальное
    имя после задачи 4.1 — «Разархивация существующего упражнения из
    файла не выполняется»).

## Impact

- `app/src/main/java/com/myworkouts/domain/usecase/ImportBackupUseCase.kt` —
  `mergeBackup` возвращает id упражнений к архивации; `invoke` применяет их
  через существующий `repository.setArchived(id, true)` (интерфейс
  репозитория не меняется).
- Тесты: `app/src/test/.../ImportBackupUseCaseTest.kt` — новые кейсы merge
  и сквозного invoke (TDD: сначала падающие).
