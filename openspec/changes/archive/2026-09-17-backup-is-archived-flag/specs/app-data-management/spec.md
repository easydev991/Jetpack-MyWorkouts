## MODIFIED Requirements

### Requirement: Формат файла резервной копии

Резервная копия SHALL быть JSON-объектом
`{ "version": 1, "exercises": [...], "entries": [...] }`, где `version` —
версия формата. Каждый элемент `exercises` SHALL содержать поля упражнения:
`name`, `category`, `measuredBy`, `isCustom`, `comment` (опционально),
`iconNumber` (опционально), `createdAt`, `isArchived`. Каждый элемент
`entries` SHALL содержать поля записи: `exerciseName`, `date`, `sets`,
`reps` (опционально), `weightKg` (опционально), `durationSec` (опционально),
`comment` (опционально), `createdAt`. Идентификаторы строк базы данных в
файле SHALL NOT храниться: связь «запись → упражнение» выражается именем
упражнения (`exerciseName` → `name`). Поле `modifiedAt` в файле SHALL NOT
храниться: восстановленная запись SHALL получать `modifiedAt`, равный
моменту импорта. Файл SHALL быть отформатирован человекочитаемо
(с отступами). Типы полей строгие: `version` — Int; `date` и `createdAt` —
Long (миллисекунды эпохи); `sets`, `reps`, `durationSec`, `iconNumber` —
Int; `weightKg` — Double; `isCustom`, `isArchived` — Boolean; строки
(`name`, `category`, `measuredBy`, `exerciseName`, `comment`) — String.
«(опционально)» означает: поле может отсутствовать или быть `null`; при
наличии — строго указанный тип, иначе файл ошибочен. `isArchived`
SHALL писаться в файл всегда как `true` или `false`, SHALL NOT
отсутствовать и SHALL NOT быть `null` — в отличие от `(опционально)`-полей
(`comment`, `reps`, `weightKg`, `durationSec`, `iconNumber`). `iconNumber`
тоже пишется всегда, но допускает значение `null`. Версия формата SHALL остаться `1`: `iconNumber` и
`isArchived` — обратно совместимые расширения. Файл, созданный до
введения `isArchived` (без этого поля в элементах `exercises`), SHALL
оставаться валидным — при его импорте упражнениям присваивается
`isArchived = false`. Чтение нового файла старой версией приложения вне
скоупа этого изменения и уже покрыто гарантией «Неизвестные поля
игнорируются» (требование «Обработка ошибок восстановления»).

#### Scenario: Структура файла

- **WHEN** резервная копия создана
- **THEN** файл начинается с объекта, содержащего `"version": 1` и массивы
  `exercises` и `entries`
- **AND** записи ссылаются на упражнения по имени, без идентификаторов БД

#### Scenario: Опциональные поля

- **WHEN** у упражнения или записи нет комментария/веса/длительности
- **THEN** соответствующее поле отсутствует или равно `null` в файле

#### Scenario: Номер иконки в файле

- **WHEN** резервная копия экспортируется
- **THEN** каждый элемент `exercises` содержит поле `iconNumber`:
  целое число либо `null`, если у упражнения нет иконки
  (поле пишется всегда, даже как `null`; «(опционально)» в списке —
  про допустимость старых файлов при импорте)

#### Scenario: Старый файл без номера иконки импортируется

- **WHEN** импортируется валидный файл версии 1, элементы `exercises`
  которого не содержат `iconNumber` (бэкап, сделанный до введения поля)
- **THEN** импорт завершается успешно
- **AND** упражнениям из файла присваивается `iconNumber = null`

#### Scenario: Признак архивации в файле

- **WHEN** резервная копия экспортируется
- **THEN** каждый элемент `exercises` содержит поле `isArchived`:
  `true`, если упражнение в каталоге помечено как архивное,
  `false` — если активно (поле пишется всегда, для активных и архивных
  упражнений одинаково)

#### Scenario: Старый файл без признака архивации импортируется

- **WHEN** импортируется валидный файл версии 1, элементы `exercises`
  которого не содержат `isArchived` (бэкап, сделанный до введения поля)
- **THEN** импорт завершается успешно
- **AND** упражнениям из файла присваивается `isArchived = false`

### Requirement: Восстановление из резервной копии слиянием

Кнопка «Восстановить из резервной копии» / "Restore from backup" SHALL
открывать системный выбор файла (SAF) без ограничения mime-типа. Выбранный
файл SHALL сливаться с текущими данными: ничего не перезаписывается,
добавляется только недостающее. Дедупликация: упражнения — по имени (без
учёта регистра), записи — по содержимому (имя упражнения, дата, подходы,
повторы, вес, длительность, комментарий). Связь записи с упражнением
восстанавливается по имени: используется существующее в каталоге
упражнение либо вставленное из файла. Записи, упражнение для которых не
найдено ни в файле, ни в текущем каталоге, SHALL быть пропущены без
провала всего импорта. Записи, не прошедшие валидацию (например,
количество подходов меньше 1 или несовместимый с типом измерения
упражнения набор полей), SHALL быть пропущены так же. Вставляемые из
файла упражнения SHALL получать `isCustom = true`: значение `isCustom`
из файла игнорируется — файл недоверенный, а вставляемое по определению
не из канонического стандартного набора. Вставляемое из файла упражнение
SHALL сохранять свой `iconNumber` из файла как есть. Вставляемое из файла
упражнение SHALL сохранять свой `isArchived` из файла как есть (в т.ч.
`true`, чтобы попасть в архив при импорте). При дедупликации
по имени (упражнение уже есть в каталоге) существующее упражнение
SHALL NOT изменяться — его `iconNumber` и `isArchived` остаются прежними.
Дедупликация по имени работает в одной локали: перенос копии между
локалями (ru ↔ en) может создать дубликаты стандартных упражнений
(вставленные получат `isCustom = true` и будут удаляемы) — принятое
ограничение формата v1. Диалог подтверждения импорта SHALL NOT
показываться: merge только добавляет. Результат — Toast об успехе
или ошибке.

#### Scenario: Успешное слияние

- **WHEN** выбран корректный файл резервной копии
- **THEN** упражнения из файла, которых нет в каталоге, добавляются
- **AND** записи из файла, дубликатов которых нет, добавляются
- **AND** существующие данные не изменяются
- **AND** показывается Toast об успешном восстановлении

#### Scenario: Дубликаты пропускаются

- **WHEN** упражнение с тем же именем уже есть в каталоге
- **THEN** новое упражнение не создаётся, записи ссылаются на существующее
- **AND** когда запись с тем же содержимым уже есть в базе
- **THEN** дубликат записи не вставляется

#### Scenario: Запись без упражнения пропускается

- **WHEN** запись ссылается на имя упражнения, которого нет ни в файле,
  ни в текущем каталоге
- **THEN** эта запись пропускается, остальные записи файла импортируются

#### Scenario: Номер иконки вставленного упражнения сохраняется

- **WHEN** упражнение из файла вставляется в каталог (имени нет в каталоге)
- **THEN** вставленное упражнение получает `iconNumber` из файла

#### Scenario: Номер иконки существующего упражнения при дедупликации не меняется

- **WHEN** упражнение из файла дедуплицируется по имени с существующим
- **THEN** существующее упражнение остаётся со своим прежним `iconNumber`

#### Scenario: Признак архивации вставленного упражнения сохраняется

- **WHEN** упражнение из файла с `isArchived = true` вставляется в каталог
  (имени нет в каталоге)
- **THEN** вставленное упражнение получает `isArchived = true` и попадает
  в архив (на экране «Упражнения» в общем списке не отображается)

#### Scenario: Признак архивации существующего упражнения при дедупликации не меняется

- **WHEN** упражнение из файла дедуплицируется по имени с существующим
- **THEN** существующее упражнение остаётся со своим прежним `isArchived`
  (значение из файла игнорируется — архивный статус в текущем каталоге
  имеет приоритет)
