# Proposal: TIME-упражнения в статистике обзора

## Why

Пользователь, тренирующийся только упражнениями типа TIME (бег, планка, скакалка), видит вкладку «Статистика» пустой — «Нет тренировок за выбранный период», хотя тренировки есть: донат и легенда считаются только по REPS-объёму, и TIME-категория не получает ни сектора доната, ни строки легенды, ни drill-down.

## What Changes

- Доли доната и сортировка категорий/упражнений — по **подходам (sets)**: универсальная единица, заменяет прежнее правило «донат по повторам» (Decision 4 архивного `overview-screen`).
- Значения легенды — в естественных единицах:
  - только REPS → «N повт.» (как сейчас);
  - TIME-объём → суммарная длительность в компактной одноединицной форме с адаптивной единицей (сек./мин./ч./дн. — пороги и округление: см. спеку);
  - смешанная категория → «N повт. · M <ед.>» (оба значения, доля в донате — по подходам).
- TIME-категории/упражнения попадают в донат, легенду и drill-down наравне с REPS.
- Пустое состояние: `isEmpty` = «нет записей за период вообще» (оба типа измерения) — только-TIME пользователь видит донат, легенду и drill-down.
- Закрытие Non-Goal архивного change'а «режим длительности в донате» — не переключаемым режимом, а постоянной поддержкой TIME.
- Вкладки «Рекорды» и «Активность» не затрагиваются (TIME там уже учтён).

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `overview-screen`: требования «Статистика — период и донат долей категорий» и «Drill-down категории в статистике» — единица долей «подходы», значения легенды с поддержкой TIME-длительности, новое правило пустого состояния.

## Impact

- `domain/usecase/ComputeCategoryStats.kt` — модели `CategoryTotal`/`ExerciseTotal` (sets + суммы reps и durationSec + состав для выбора единицы), расчёт долей по подходам, TIME-категории в итогах.
- `ui/state/OverviewUiState.kt` / `OverviewViewModel.kt` — `isEmpty` по наличию записей периода.
- `ui/screens/overview/StatsScreen.kt` — донат/легенда по подходам, формат значения легенды (адаптивная длительность), превью-демо с TIME-категорией.
- `ui/util/DurationFormatter.kt` — компактный одноединицный форматтер длительности (новая функция в существующем файле).
- Ресурсы: новые строки единиц с точкой (сек./мин./ч./дн.) в `values/` (ru) и `values-en/` (en).
- Тесты: `ComputeCategoryStatsTest`, `OverviewViewModelTest`, `StatsScreenTest`; `DurationFormatterTest` расширяется тестами компактного форматтера, плюс новый тест-класс хелпера значения легенды.
